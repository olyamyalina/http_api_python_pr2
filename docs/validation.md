# Результаты проверки этапов 1, 2 и 3

Проверено 9 ноября 2026 года на Windows, Python 3.13.
Хранилище: SQLite через SQLAlchemy ORM; отдельная Session на операцию.

## Автоматические проверки

Команда: `scripts\check.bat`.

```text
tests/test_barcode.py: 14 passed
tests/test_api_mbt.py: 1 passed

Name                      Stmts   Miss Branch BrPart  Cover
-----------------------------------------------------------
src/ean8_service/api.py      111      0     16      0   100%
-----------------------------------------------------------
TOTAL                       111      0     16      0   100%
```

Покрытие измерено только на Hypothesis RuleBasedStateMachine, с учётом
ветвей. Все 11 обработчиков HTTP API выполнены. 111 операторов и 16 ветвей
покрыты полностью. HTML и машинный JSON-отчёт создаются локально в
`output/coverage/` и `output/coverage.json`.

Модель API генерирует до 40 примеров последовательностей до 30 переходов.
Число последовательностей не равно числу отдельных HTTP-запросов: инварианты
проверяются после каждого перехода. Создание, изменение записей, ошибки
и авторизация проверяются отдельными правилами. Инициализация только
настраивает приложение. Ошибочные запросы выбираются по коротким именам;
большое тело создаётся внутри правила и не загромождает сценарий ошибки.
Полнота покрытия подтверждается отчётом coverage для выполненного запуска.

## Сквозная проверка

Отдельно запущен сервер `python -m ean8_service.server` на свободном
локальном порту. Выполнен `scripts/demo_client.py` через реальный HTTP
и стандартный urllib-транспорт, без WSGI-подмены:

1. Без авторизации сервер вернул 401.
2. С Basic Auth создан Account.
3. Отправлен Message с двумя кодами.
4. CLI запущен через subprocess, получен Feedback.
5. Декодированный PDF открыт средствами PyMuPDF; одна страница,
   две этикетки, контрольные цифры 12345670 и 96385074.
6. В тестовом режиме получен успешный Feedback с пустым результатом.
7. Проверены формат SQLite-файла и чтение записей через новый Store.
8. Вставка задания для несуществующего аккаунта отклонена внешним ключом.
   После ошибки новая запись отсутствует, подключения освобождены.

Пять PDF этапа 1 повторно созданы и открыты средствами PyMuPDF.
Пример из 12 кодов содержит две страницы. Подробности входных файлов
приведены в `docs/stage1-examples.md`.
