Покрытие измерено только на Hypothesis RuleBasedStateMachine, с учётом
ветвей. Все 11 обработчиков HTTP API выполнены. 110 операторов и 16 ветвей
покрыты полностью. HTML и машинный JSON-отчёт создаются локально в
`output/coverage/` и `output/coverage.json`.

Модель API генерирует 20 примеров последовательностей до 20 переходов,
модель исполнения - 10 примеров до 8 переходов. Число последовательностей
не равно числу отдельных HTTP-запросов: инварианты проверяются после каждого
перехода. Начальные перестановки обеспечивают обязательную проверку
ошибок, авторизации и обеих ветвей изменения принадлежности Message.
