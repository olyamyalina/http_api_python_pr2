# Проверка требований к оформлению

Проверены все правила страницы 5 сборника, включая тесты и скрипты.
Команда воспроизведения: `python scripts/check_style.py`.
Она также запускается первой в `scripts/check.bat`.

| Правило | Проверка | Результат |
|---|---|---|
| С1 | Наличие README.md | Есть |
| С2 | Наличие .gitignore | Есть |
| С3 | Наличие src | Есть |
| С4 | Наличие tests | Есть |
| С5 | Наличие run.bat | Есть |
| С6 | Сообщения коммитов Conventional/Scoped Commits | Соответствуют |
| Г1 | Архивы среди отслеживаемых файлов | Отсутствуют |
| Г2 | Бинарные файлы среди отслеживаемых файлов | Отсутствуют |
| Г3 | Служебные файлы Python в Git | Отсутствуют |
| Г4 | Артефакты сборки в Git | Отсутствуют |
| Г5 | Настройки редакторов в Git | Отсутствуют |
| Р1 | Не более 1000 строк в файле Python | Максимум 252 |
| Р2 | Не более 80 символов в строке Python | Максимум 80 |
| Р3 | Не более 40 физических строк функции | Максимум 30 |
| Р4 | Не более 7 аргументов функции | Максимум 5 |
| П1 | Отсутствие комментариев вне docstring | Подтверждено tokenize |
| П2 | Цикломатическая сложность | Максимум 10 по Radon |
| П3 | Имена по PEP 8 | Ruff, группа N: без нарушений |
| П4 | Оформление по PEP 8 | pycodestyle и Ruff: без нарушений |
| П5 | Числовые литералы в сравнениях | Отсутствуют, проверка AST |

Порог сложности в сборнике не указан. В проекте принят предел 10;
он закреплён в конфигурации Ruff и проверке Radon. Radon учитывает
условия, генераторы, assert и вложенные функции. Размер функции считается
включая docstring, пустые строки и декораторы. Аргументы считаются с self,
позиционными, именованными, *args и **kwargs.

Проверены все 14 файлов Python: исходный код, тесты и служебные скрипты.
Проверка чисел применяется также к литералам внутри кортежей, выражений
и индексов в операндах сравнения. HTTP-коды в проверках заменены на
HTTPStatus; ограничения EAN-8, число результатов и окно отчёта обозначены
именованными константами. Сложный инвариант модели разделён на отдельные
проверки аккаунтов и сообщений.

Правила Г1-Г5 проверяются по `git ls-files`: локальные PDF, окружение Python
и HTML-отчёт остаются на диске, но исключены из репозитория.

Требование страницы 4 о публичном доступе к репозиторию отдельно от
оформления кода: удалённый репозиторий пока не опубликован. Инструкция
публикации находится в README.md.
